# 比較元のアプリとの対応表

本人の依頼（2026-11-02）で、比較元のアプリにあってこのリポジトリになかったものを棚卸しし、すべてを「実装」か「対象外（理由）」に分けた。比較元のコードは写していない。振る舞いだけを参考にして、このリポジトリの書き方で作り直した。

「実装」はコードと自動試験があるという意味で、本番で安全と判定したものではない。未確認の項目は [証拠台帳](evidence-register.md) の `evidence-pending` を見る。

## サーバーと基盤

| 項目 | 判定 | 場所・補足 |
|---|---|---|
| API サーバー（既存の全操作、監査の記録） | 実装 | `server/`。OpenAPI は106操作 |
| データの保存と移行 | 実装 | SQLite（`node:sqlite`）と `server/db/migrations.ts`。記録の本文は `records` 表の JSON |
| CSRF、冪等、権限リビジョン、既定の拒否 | 実装 | `server/http/app.ts`、`server/http/rules.ts` |
| `/health`、`/ready`、`/version` | 実装 | `server/http/routes/operational.ts`。版の印は画面と API で同じ値 |
| 運営者の操作（延長、停止） | 実装 | `server/cli.ts`。HTTP の経路なし |
| 変更の記録 | 実装 | 別のファイル `audit.db`（`FAMILY_HUB_AUDIT_DB`、権限 0600）の hash の鎖。家族の記録は管理者だけ（`audit.read`）、アカウントの記録は本人だけ。既定で24か月残す。別のファイルにしても同じ OS の利用者や root からは守れず、改ざんに気づけるのは外に残した基準点（運用ログ、バックアップの目録、`audit_anchors`）の範囲だけ。最後の基準点より後の切り捨ては検出できない |
| 鍵の入れ替えと、鍵をなくしたとき | 実装 | `FAMILY_HUB_KEYS` と `FAMILY_HUB_ACTIVE_KID`（なければ `FAMILY_HUB_SECRET` を kid `legacy`）。`keys status`・`keys rotate`・`keys retire <kid>`、`totp reset --user <id>`。鍵をなくしても起動し、その人は回復コードかパスキーでサインインして確認コードを設定し直す |
| バックアップと復元 | 実装（運営者の命令） | `server/backup/`。`FAMILY_HUB_BACKUP_DIR` と `FAMILY_HUB_BACKUP_KEY` を設定したとき、毎日（既定 03:00）作り、`FAMILY_HUB_BACKUP_KEY` で暗号化する。鍵は置き場所とも API の機械とも別に保管する。世代は日7・週4・月6で、削除した記録やアカウントも最長6か月残る。`backup now`・`backup list`・`backup verify <id>`、`restore <id> --to <dir>`。アプリの画面からは操作しない |
| 30日の削除ジョブ、通知の生成 | 実装 | `server/jobs.ts` |

## 対象外

| 項目 | 理由 |
|---|---|
| 中身のない機械学習の骨組み | 動く中身がなく、写すと見かけだけの機能になる |
| Mac アプリ、launchd、Tailscale の運用 | 比較元の運用環境に固有で、公開リポジトリに実の接続情報を入れない |
| Rust の補助 | TypeScript の共有の規則と標準ライブラリで足りる |
| 呼び出し元のない telemetry | 使われていない。外部送信を増やさない |
| Web に意味のない iOS 機能（写真アプリの元を消す、TestFlight の通知） | ブラウザでは実現できない、または意味がない |
| iTunes の BGM 選択 | 新しい外部送信になる。BGM は Web Audio の合成だけにする |
| 実データ、実ホスト名、実在の人の情報 | 公開リポジトリのため。見本はすべて架空 |
| 管理コンソールの本物の経路と形だけの確認コード | 本人の決定。見かけだけの安全策を作らない |

## 意図した違い

| 項目 | このリポジトリの決定 | 理由 |
|---|---|---|
| 月末の繰り返し | `BYMONTHDAY=28,29,30,31;BYSETPOS=-1`（1/31→2/28→3/31） | iCal と互換で、家賃日などに正しい。比較元の、2月のあと28日へずれる動きは写さない |
| HEIC | 受け付けない。理由を示して JPEG での保存を案内 | 配布版の sharp で読めない |
| 再開できるアップロード | tus 1.0 の手順を `server/http/routes/media.ts` に自前で実装。計画にあった `@tus/server` は使わない | 依存を増やさず、経路の宣言と認可の仕組みに合わせる |
| 2FA | サーバーで検証する本物の TOTP。秘密は暗号化保存、同じコードの再利用を防ぎ、回復コードはハッシュで1回限り | 比較元は端末の中だけで検証し、管理者の確認も形だけだった |
| スライドショー | 自動で進む完成形 | 比較元の Web 版は途中のものがあった |
| 隠す表示、端末への保存 | 実際に効く完成形 | 同上 |
| 週の始まり | 日曜はじまり | カレンダーの既存の表示に合わせる |
| 動画の位置情報 | MP4/MOV の位置情報を直接消す。解析できない動画は拒否 | 既定で消すという約束を動画でも守る |
| 助言の名前 | 決定的な集計で、「AI」とは名乗らない | 能力を誇張しない |
| 読み取りの補助の接続先と、家族ごとの同意 | 同じ機械か家庭内だけに接続し、外部へは送らない。家族ごとの同意の仕組みは作らない（未決事項から閉じた） | 本人の決定（2026-11-03）。外部へ送らないので、家族ごとに送信先を選ぶ必要がない |
| ブランド | 「よりどころ」を維持。比較元の名をリポジトリに書かない | `npm run audit:ui` で検査 |

## iOS アプリ（iPhone と iPad）

Web の画面と同じことを、Swift（SwiftUI）のアプリでもできるようにした（`ios/`、作り方と決めたことは [docs/ios/README.md](ios/README.md)）。アプリは同じサーバーの API を使い、見本のモードでは Web の見本の規則を JavaScriptCore で動かす。「実装」はコードと自動試験（`swift test` と、iPhone・iPad のシミュレーターの UI の試験とアクセシビリティの監査）があるという意味。使い方ごとの試験は `docs/verification/use-cases.json` の products の I に名指ししてある。

| 領域 | アプリ | 補足 |
|---|---|---|
| サインイン・登録・再設定・はじめに・無操作の期限・本人確認 | 実装 | パスワードと確認コード。パスキーでのサインインは、ドメインの設定（webcredentials）ができるまで出さない |
| 今日・予定・タスク・メモ・家計・アルバム | 実装 | 計算は Swift に移し、Web の TS の関数の答え（入力と答えの組）で照らす |
| 場所・ヒント・検索・通知・すぐに追加 | 実装 | 端末の通知（ローカル）は、利用者が選んだときだけ予約する（Web にはない） |
| 設定の12のタブ | 実装 | パスキーの追加は、ドメインの設定ができるまで出さない（Web で追加したものは表示する） |
| 送れなかった変更 | 実装 | Web と同じ範囲（予定・タスク・メモの追加と変更）。鍵は Keychain、記録は端末のファイルに暗号にして置く |
| 記録どうしの関連づけ | 対象外 | Web にも画面がない |
| 運営者の命令、管理コンソールの見本 | 対象外 | 運営者の道具。利用者のアプリには入れない |
| App Store での配布と課金 | 未決 | 開発用の署名だけで実機に入れている。論点は [docs/legal/ios-distribution.md](legal/ios-distribution.md) |
