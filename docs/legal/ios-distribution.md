# iOS アプリの配布と課金の論点（2026-11-09 時点）

> **これは弁護士による確認ではなく、法的助言でもありません。** App Store の審査の指針と、Apple の日本向けの条件は変わります。出す前に、その時点の原文と、弁護士の確認を受けてください。

今は開発用の署名で実機に入れているだけで、TestFlight にも App Store にも出していない（[docs/ios/README.md](../ios/README.md)）。出すときに決めること・確かめることを、ここにまとめる。

## 課金

| 論点 | 今のアプリ | 決めること |
|---|---|---|
| アプリの中で機能を開けるときは、App 内課金を使う（審査の指針 3.1.1） | 利用期間が終わった画面は状態を示すだけで、買う画面や外のページへの案内は置いていない。延長は運営者の命令だけ | App 内課金で売るか、アプリでは売らないか |
| 日本のスマホソフトウェア競争促進法（2025年12月に全面施行） | まだ何もしていない | 日本で、App 内課金のほかの決済や、外のページへの案内を使うか。使うなら、その時点の Apple の日本向けの条件（手数料・表示・届け出）を確かめる |
| Web で買った利用期間をアプリで使う | サーバーの利用期間をそのまま使う | アプリの中で Web の購入への案内を出すかどうか（上の2つの条件による） |

## 審査と表示

| 論点 | 今のアプリ | 残っていること |
|---|---|---|
| アプリの中でアカウントを削除できる（5.1.1(v)） | 設定の「アカウント」から削除できる | — |
| ほかのサービスでのサインイン（4.8） | 自前のアカウント（メールとパスワード、確認コード）だけ。ほかのサービスでのサインインは使わない | ほかのサービスでのサインインを足すなら、そのときに確かめる |
| App のプライバシーの表示（栄養表示） | 送るもの: メールアドレス、名前、家族の記録（予定・タスク・メモ・家計・写真と動画）、約100m に丸めた位置か検索語（外部の場所検索に同意したときだけ）。広告と分析には使わない | 表示の項目を、規約の草案と照らして決める |
| プライバシーの宣言のファイル（PrivacyInfo.xcprivacy） | まだない。UserDefaults（この端末の表示の設定）を使っている | 理由つきの API の宣言を足す |
| 暗号の輸出の届け出 | https の通信と、端末の中の暗号（送れなかった変更の AES-GCM）だけ | 免除の扱いを確かめ、`ITSAppUsesNonExemptEncryption` を決める |
| 年齢 | 登録で生年月日を受け、18歳未満は保護者の同意を求める（Web と同じ） | 年齢の区分の質問票。子ども向けのカテゴリーには出さない |
| 位置情報と通知の許可 | 位置は使うときに1度だけ求める。端末の通知は利用者が選んだときだけ求める | — |
| パスキー | ドメインの設定（AASA と webcredentials）ができるまで、追加の入口を出さない | 本番のドメインで AASA を配り、entitlement を足す |
| 外部の場所検索（OpenPOI API）の表示 | 同意の画面と設定に、送るもの・送らないもの・利用規約・出典を出す | — |

## 次にすること

1. 課金の方針（売るか、どこで売るか）を決める。
2. App のプライバシーの表示とプライバシーの宣言のファイルを、規約の草案と照らして作る。
3. TestFlight の内部の試験から始める。
