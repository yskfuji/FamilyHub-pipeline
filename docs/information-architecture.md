# 情報設計とタスク設計

## 目的

「記録する」より先に「今日どう動くか」を支援する。入口をドメイン別のカード一覧にはせず、Todayを判断順に構成する。

```text
公開
├── /welcome
├── /auth
└── /onboarding

世帯内
├── /today                 要確認 → 時間軸 → 自分の担当 → 未精算 → 天気影響
├── /calendar/:eventId?    月・週・一覧 → 予定詳細 → この予定/これ以降/すべて
├── /tasks/:todoId?        担当/確認フィルタ → 状態遷移
├── /notes/:memoId?        本文 → 添付検査状態 → OCR/原本照合
├── /budget                月次 → 相手別残高 → 支出/精算
├── /insights              根拠 → 現在状態 → 任意の次操作
├── /settings/*            世帯/認証/通知/表示/関連リンク
└── /showcase              内部監査buildだけの画面・テーマ・異常状態
```

## 主なタスク

| ユースケース | 最短経路 | 失敗・復旧 |
|---|---|---|
| 今日の確認事項を終える | 今日 → 要確認 → タスク詳細 → 完了 | 競合時は上書きせず、差分確認を促す |
| 繰り返し予定を変更/削除 | 予定 → 月/週/一覧 → 予定詳細 → 編集範囲選択 | この予定/これ以降/すべてを明示し、既定はこの予定だけ。削除は確認画面 |
| 紙のお知らせを共有 | Notes → 添付 → 隔離 → clean後に閲覧 | 拒否理由、許可形式、再選択を表示 |
| 立替を精算 | Budget → 相手別 → 支出行 → 精算記録 | 二重精算は競合として拒否、取消経路を残す |
| 情報を横断検索 | グローバル検索 → 結果 → 詳細URL | 一致なしを静かな空状態で示す |
| 家族の権限/招待を管理 | 設定 → 世帯 → メンバー権限/招待作成 | 唯一の管理者の降格を拒否。招待は24時間・1回でコードを作成直後だけ表示 |
| 認証とセッションを管理 | 設定 → セキュリティ → パスキー/パスワード/端末 | デモ登録を明示。パスワード入力は閉じると破棄。対象端末だけ確認後に終了 |
| 通知を調整 | ベル/Settings → 通知 → 延期/停止/設定 | 現在時刻と状態を表示し、30分延期と停止を常に明示 |

## レスポンシブ原則

- 760px超: 左レール、本文、必要時の右詳細ペイン。
- 760px以下: 今日/予定/タスク/家計/その他の5項目ボトムナビ。詳細は全幅。
- コンテナの幅に応じてカードを縮退。長い日本語は `overflow-wrap` とGridの `minmax(0,1fr)` で処理し、水平オーバーフローを隠さない。
- アイコン単独操作には必ずアクセス可能名を付ける。主要な意味は本文ラベルも併記する。
