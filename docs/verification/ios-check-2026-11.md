# iOS アプリの動作確認（2026年11月）

iOS アプリ（`ios/`、段階 S0〜S8）を、自動の試験と、失敗の場面を起こす確認で確かめた結果。最後に、端末でしか確かめられないことを、本人が実機で見る一覧にした。

## 何で確かめたか

| 確かめたこと | 方法 | 結果 |
|---|---|---|
| 型・計算・通信・見本の規則 | `swift test --package-path ios/Packages/FamilyHubKit`（Web の TS の関数の答えと照らす組、偽の応答での経路と本文、見本の規則、未送信の変更の暗号） | 通った |
| 画面の使い方とアクセシビリティの監査 | `npm run verify:ios`（iPhone 17 と iPad Pro 11 のシミュレーター。見本のモードで各画面の主な使い方を動かし、昼と夜、文字を最大にしたときに監査する） | 通った |
| サーバーにつないだときの失敗の場面 | `npm run verify:ios:live`（使い捨てのサーバーと切り替えのできる中継。iPhone 17） | 通った（下の表） |
| 実機に入れて起動する | `npm run ios:device`（開発に使う iPhone） | 下の「実機」 |
| Web の側 | `lint`・`typecheck`・`test:unit`・各 `build`・静的な監査（security・ui・css・illustrations・controls・contract・licenses・routes・use-cases）・e2e（Chromium と WebKit）・a11y・contrast・Lighthouse・`test:real` | 下の「Web」 |

## サーバーにつないで起こした場面（`ios/UITests/LiveServerUITests.swift`）

| 場面 | 起こし方 | 確かめたこと | 結果 |
|---|---|---|---|
| つながらない | 中継で、アプリからの通信を切ってからタスクを追加する | 未送信の変更として残る。戻してから「すべて送信」すると、サーバーに1件だけ届く（送り直しでも同じ冪等の鍵） | 通った |
| 版の競合 | アプリでタスクの編集を開いている間に、試験の側から同じタスクを変える | 保存すると「別の端末でタスクが更新されています」と出る | 通った |
| 本人確認 | 本人確認の時間（この確認では20秒）を過ぎてから招待を作る | パスワードを聞き、入れると同じ操作が続いて招待コードが出る | 通った |
| 権限の変更 | 管理者が試験の側から、蓮さんの「家計を見る」を止める | アプリで読み直すと、家計がその他の一覧から消える | 通った |
| 無操作の期限 | 無操作の時間を1分にする | 予告が出て、過ぎるとサインインの画面に戻る | 通った |
| サインインとサインアウト | パスワードでサインインし、設定からサインアウトする | 今日の画面が開き、サインアウトでサインインの画面に戻る | 通った |

## 確かめる途中で見つけて直したこと

| 見つけたこと | 直したこと |
|---|---|
| Debug のビルド（シミュレーターと実機で使う形）の `App/Info-Debug.plist` に、位置の許可を求める文がなかった。現在地を使うと、アプリが止まるところだった | 足した。`verify:ios` の最初に、`Info.plist` の鍵が `Info-Debug.plist` にすべてあることを確かめる手順を足した |
| 試験の「はじめから」（`-FHResetPreferences`）が、前の試験のサインインの cookie を残していた | 設定と一緒に cookie も消すようにした |
| 未送信の変更の知らせが、画面の下の最後の行に重なることがあった | 知らせがある間は、画面の下に余白を足した |
| 設定の画面を一覧（Form）で作ると、アクセシビリティの監査が最初の一覧の画面の文字の大きさと濃さを測り損ねた。iPad では読み込みの途中の薄い表示を測った | 設定のタブの中身をカードの形にした。監査は、指摘があれば3秒待って測り直し、2回とも出た指摘だけを失敗にした |

## 本人に実機で見てほしいこと

シミュレーターでは確かめられないことです。結果の欄に ○（問題なし）・×（問題あり）を書き、×のときは何をしたら何が起きたかを下に書いてください。

| # | 確かめること | 手順 | 結果 |
|---|---|---|---|
| I1 | 写真を選ぶ | アルバムを開き「写真や動画を追加」→「写真や動画を選ぶ」で、写真アプリの写真（HEIC）と動画を1つずつ選び、「n件を送る」で送る。送れるか。開くと見えるか | |
| I2 | メモの添付 | メモを追加し、写真とファイル（PDF）を付ける。開くと見えるか。「保存」から「ファイルに保存」できるか | |
| I3 | 位置の許可 | 支出を追加し「場所を追加（任意）」→「現在地」を選ぶ。許可を聞かれるか。断ったときに手入力へ進めるか | |
| I4 | 通知 | 通知の一覧で「この端末にも通知する」を入れる。許可を聞かれるか。時刻に届くか。押すと記録が開くか | |
