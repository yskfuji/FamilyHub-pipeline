# 光学・視覚監査

状態: 2026-09-30に固定シード・DPR 2で79枚を撮影し、HTMLギャラリーと新規操作画面の原寸を人手確認した。採用画像は `artifacts/screens/gallery.html` と同じファイル名で追跡する。

## 検査項目

- 320〜1920pxでdocument/main panelの水平オーバーフローが0。
- 長い日本語、数値、badge、CTAの切れ・重なりがない。
- 見出しが次の内容から孤立しない。カード密度と余白の段階が読み取れる。
- 色だけで状態を表さず、明暗両テーマで意味が衝突しない。
- フォーカスがsticky header、drawer、bottom navに隠れない。
- 空、読込、オフライン、競合、期限切れ、添付隔離、荒天が区別できる。

## 人手結果

- 390×844、834×1112、1440×1000の全主要画面、設定5カテゴリ、空・オフライン・競合・セッション失効・期限切れ招待・添付隔離・荒天、重要5画面の夕景テーマを確認した。通知センター、予定編集、権限編集、パスワード変更はモバイル/デスクトップの操作中状態も採用した。
- 初回確認で、390pxのToday時間軸に日本語が1文字ずつ折り返す欠陥を発見。原因は汎用 `.list-row > :first-child.time` が時刻セルを全列へ広げ、CSS Gridの自動配置で本文を40px列へ追い出していたこと。時間軸内だけ列指定を上書きし、再撮影で通常折返しを確認した。`overflow-x`による隠蔽は使用していない。
- 添付隔離シナリオでbadgeは「隔離中」なのに説明が「検査済み」になる矛盾を発見。fixture変換時にstatusとstatusMessageを同時更新するよう修正し、再撮影で整合を確認した。
- 初回axeで暗背景のブランド補助文字、月外日、進捗ARIA、円グラフARIAの4原因を検出。色トークンまたは意味構造を修正後、3ブラウザ36件でserious/critical 0を確認した。
- 追加操作監査で、モーダルの全画面撮影が固定レイヤーより長い背景を露出する納品上の欠陥を発見。操作中8枚だけviewport撮影へ切り替え、背景露出と固定ナビの重複を除去した。
- 44px走査でショーケースの9分割ボタンが約35px幅へ縮退する原因を検出。`overflow`で隠さず、シナリオ群を最小76pxのauto-fit gridへ変更し、3ブラウザ・390pxの全表示ボタンで44×44 CSS px以上を確認した。
- 通知Drawer、予定編集、権限編集、パスワード変更を原寸確認し、切れ・重なり・色意味衝突を認めなかった。モバイル予定編集は内容が一画面を超えるため内部スクロールし、操作ボタンは末尾に置く。
- 切れ・重なり、孤立見出し、状態の色依存、長文の水平欠落は採用画像で認めなかった。モバイルの固定ボトムナビは閲覧中の実UIとして全ページ画像の途中に写るが、本文には十分な下余白があり、スクロール末尾を隠さない。
- VoiceOver + Safariの実機読み上げ順は `evidence-pending`。WebKit自動検査と同一視しない。
