# 実家庭ユーザー評価プロトコル（evidence-pending）

## 設計

- 最低6世帯、12名。各世帯から日常調整を共同で行う2名を募集。
- 順序効果を抑えるため、タスク順はLatin squareで均衡化。
- 片方が登録、もう片方が確認するペアタスクと、個別タスクを分ける。
- 端末、習熟、家族構成、アクセシビリティ要件を記録。小標本なので母集団一般化は控える。

## タスク

1. 招待を受けて世帯へ参加。
2. 繰り返し予定の「今回のみ」を変更。
3. Todoを担当し、相手にレビューを依頼。
4. 学校書類を添付し、隔離状態とOCRを説明。
5. 3人分の支出を割り、相手が精算。
6. Todayから雨の影響を確認し、予定を維持。
7. オフライン後に復旧し、競合を解決。

## 指標

- 課題成功率（独力/助言あり/失敗）とWilson 95%信頼区間。
- 所要時間、誤操作数、戻り回数、支援要求数。
- 各タスク後SEQ（7件法）、終了後SUS。
- 発話と観察は仮説生成用。小標本の割合差を有意差として誇張しない。
- 事前成功基準: 主要タスク独力成功率80%以上、重大な権限/金額誤り0、SEQ中央値5以上。SUSは記述統計と区間を報告し、単一閾値だけで合否を決めない。

## 解除条件

`evidence-pending` は、データ収集、匿名化、二名によるコーディング照合、集計スクリプト、除外理由、反証事例を成果物へ追加するまで解除しない。
