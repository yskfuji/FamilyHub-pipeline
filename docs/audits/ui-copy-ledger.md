# 日本語UI文言台帳

## 採用方針

- 短い操作名には同種サービスで一般的な「予定」「タスク」「メモ」「通知」「招待」を使う。
- 内部値 `owner/adult/child/guest` は表示せず、「管理者／大人のメンバー／子どもメンバー／ゲスト」へ写像する。
- 実装方式ではなく、利用者に起きることと次の行動を説明する。
- 外部リンクは対象名と「新しいタブ」を示し、安全性を断定しない。
- 見出しは抽象的な標語ではなく、その画面で確認・操作できる内容を表す。たとえば「根拠の見える気づき」ではなく「確認しておきたいこと」とする。
- 予定とタスクの繰り返し範囲を分け、対象を名詞まで含めて示す。短い「今回のみ」「以降」「系列全体」は使わない。
- ボタンは結果を予測できる動詞句にする。「はい」「確定」「詳細」だけの操作名を避ける。
- 読み込み中、データなし、失敗、権限不足、接続切れ、競合には、現在の状態と次にできる操作を示す。

## 監査範囲

表示用の共通語彙は `src/content/ja.ts` へ集約した。通常配布画面と内部監査画面の全 `.tsx` に加え、固定データ、モックの成功・失敗文、入力検証文、オフライン保存文を静的走査する。対象には次を含む。

- ページ見出し、カード見出し、説明、ボタン、リンク、タブ、トグル、選択肢
- Dialog、Drawer、Toast、通知本文、空・読込・失敗・競合・権限不足の状態文
- ラベル、補足、placeholder、`aria-label`、画像代替テキスト
- ロール名、利用状態、公開範囲、タスク状態、添付状態、通知状態、繰り返し範囲
- fixtureとgatewayから画面へ届く文字列、内部監査画面、納品用HTMLギャラリー

静的監査では、未翻訳の英語、内部enum、直訳調または実装者向けの既知語を検出し、通常配布物に内部監査ルート・文言・source mapが入っていないことも検査する。OCR、URL、製品名、ファイル形式名など、意味や固有名を変えられない語だけを例外とする。

## 根拠と限界

- [Microsoft To Do](https://support.microsoft.com/ja-jp/todo/add-due-dates-and-reminders-in-microsoft-to-do)は「タスク」「期限日」「リマインダー」「繰り返し」を使う。
- [Google カレンダー](https://support.google.com/calendar/answer/12132599?co=GENIE.Platform%3DDesktop&hl=ja)は繰り返すタスクの適用範囲に「このタスクのみ」「すべてのタスク」等を使う。ただし同ページはAI翻訳を含む可能性を明記しており、単独の日本語品質根拠にはしない。
- [AppleのiCloudカレンダー](https://support.apple.com/ja-jp/guide/icloud/mm6b1a9479/1.0/icloud/1.0)は「予定」「参加者」「アクセス権」「参加依頼」を使う。
- [Appleのファミリー共有](https://support.apple.com/ja-jp/guide/personal-safety/ips75b3b794f/web)は「管理者」「成人」「子供」「メンバー」を使う。ただし本アプリの権限モデルは同製品の再現ではない。
- [TimeTree](https://support.timetreeapp.com/hc/ja/articles/900006199983-%E5%85%B1%E6%9C%89%E3%82%AB%E3%83%AC%E3%83%B3%E3%83%80%E3%83%BC%E3%81%B8%E5%8F%82%E5%8A%A0%E3%81%97%E3%81%9F%E3%81%84)は「共有カレンダー」「招待URL」「メンバー」を使う。
- [デジタル庁デザインシステム](https://design.digital.go.jp/dads/components/input-text/usage/)は入力欄のラベルを常に表示し、補足やエラーを項目と対応付ける構成を示す。語彙集そのものではないため、操作文の自然さを保証する資料とは扱わない。

以上は公開中の日本語版公式資料を比較した定性的な収束であり、語の理解率や選好を測った無作為標本の統計研究ではない。「すべての日本語利用者に普遍的」とは断定しない。自動走査は既知の不適切語の再発を防げるが、自然さを実証するものではないため、日本語母語話者2名の独立レビュー完了までは `evidence-pending` とする。
