# 日本語UI文言台帳

## 採用方針

- 短い操作名には同種サービスで一般的な「予定」「タスク」「メモ」「通知」「招待」を使う。
- 内部値 `owner/adult/child/guest` は表示せず、「管理者／大人のメンバー／子どもメンバー／ゲスト」へ写像する。
- 実装方式ではなく、利用者に起きることと次の行動を説明する。
- 外部リンクは対象名と「新しいタブ」を示し、安全性を断定しない。

| 修正前 | 修正後 | 判断 |
|---|---|---|
| Todo | タスク | Microsoft To Do等の日本語UIに合わせる |
| レビュアー | 確認する人 | 家族利用で役割を推測しやすくする |
| 系列全体 | すべての予定 | Appleカレンダーの日本語に近づける |
| owner / active | 管理者 / 利用中 | 内部enumを利用者へ露出しない |
| 安全な新しいタブで開く | 対象名を開く（新しいタブ） | HTTPSだけで安全を保証しない |
| WebAuthn ceremony等 | 本人確認画面が開く | 実装語を結果と行動へ翻訳する |
| リソース | 関連リンク | 設定対象を具体化する |
| Asia/Tokyo | 日本標準時（東京） | 保存値ではなく利用者が選ぶ意味を示す |
| Set up | 初期設定 | 日本語画面内の不用意な英語を除く |

fixture由来文言、placeholder、`aria-label`も静的監査対象に含める。OCRとURL、製品名など意味を変えられない語だけを例外とする。文言収束は製品比較に基づく定性的判断であり、統計的な普遍性は主張しない。日本語母語話者2名の独立レビュー完了までは `evidence-pending`。
